# TIL (Today I Learned)

開発中に調べて分かったことを、あとで検索して引ける短い技術メモとして残す。
1ファイルに1テーマを置き、フォルダは技術や道具ごとに分ける。

## フォルダ構成

```text
til/
├── database/   SQL とデータベース
├── github/     GitHub と gh コマンド
├── mise/       mise によるツールのバージョン管理
└── prettier/   Prettier の設定と挙動
```

## 書き方

- 1ファイル1テーマにする。日付ごとでなくトピックごとにファイルを作り、あとで検索しやすくする
- 中身は数行のメモとコードスニペットでよい
